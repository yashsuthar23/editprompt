# EditPrompt V7.7 Update

## Video provider upgrade
- Added optional server-side fal.ai Wan 2.2 Text-to-Video and Image-to-Video support.
- Added optional Replicate Wan 2.2 Text-to-Video and Image-to-Video fallback.
- Provider order is fal.ai → Replicate → Hugging Face ZeroGPU → Pollinations/Gemini when configured.
- Paid providers are explicitly controlled by `PAID_VIDEO_ENABLED=true` and `FREE_ONLY_MEDIA=false`; API keys are never sent to the browser.
- Hugging Face remains available as an optional free fallback, but the app no longer treats its ZeroGPU quota as the only video path.
- Video results are downloaded to the existing local media store, so the existing preview/download/share/library flow remains unchanged.

## Configuration
Set `FAL_KEY` for fal.ai. Optional Replicate fallback uses `REPLICATE_API_TOKEN`.

Default models:
- `fal-ai/wan/v2.2-a14b/text-to-video`
- `fal-ai/wan/v2.2-a14b/image-to-video`
- `wan-video/wan-2.2-t2v-fast`
- `wan-video/wan-2.2-i2v-fast`

Run `npm install`, `node --check server.js`, then `npm start`.
