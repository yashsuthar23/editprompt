# EditPrompt V7.2.2 — Local CPU Video Job Fix

- Hugging Face ZeroGPU video renders now run in the background instead of holding the HTTP status request open for the entire render.
- This prevents the previous 20-minute request timeout while Hugging Face ZeroGPU is still rendering.
- Local CPU video uses a lower 4:5 render canvas (384x480) to reduce CPU workload while preserving the requested aspect ratio.
- Local render timeout defaults to 120 minutes.
- The existing CPU preview cap remains 16 generated frames at 24 FPS (about 0.67 seconds). This is intentional: a true 10-second 24 FPS CPU Wan2.2 render would require 240 generated frames and is not practical on the current CPU-only setup.
- The job status endpoint stays responsive while the local render is running.
