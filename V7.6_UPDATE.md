# EditPrompt V7.6 Update

## Main application
- Added persistent prompt versions with generated/improved/manual versions.
- Added version list, restore and duplicate/search APIs.
- Added persistent video queue listing, cancellation and retry APIs.
- Added safer server-side cancellation state so cancelled jobs do not save late provider output.
- Added UX recovery controls for failed video jobs.
- Added offline indicator and Ctrl/Cmd+Enter generation shortcut.
- Added security response headers, API no-cache policy and security event logging for admin/OTP/media controls.

## Admin
- Added AI & Media monitoring tab.
- Added provider availability summary, video job status and admin video-job cancellation.
- Added Security Events tab.
- Added recent authentication/media-control security event visibility.

## Notes
- No paid video provider is silently enabled by this update.
- Existing provider/quota behavior remains controlled by the current .env configuration.
- Run `npm install` after replacing the project, then `node --check server.js` and `npm start`.
