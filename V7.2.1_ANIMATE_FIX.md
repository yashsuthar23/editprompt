# V7.2.1 Animate Image Fix

## Fixed
- Animate Image no longer leaves the button disabled after a failed request.
- Hugging Face depleted-credit errors are converted to a clear message.
- Pollinations HTTP 402 / zero-balance errors are converted to a clear message.
- Hugging Face ZeroGPU connection failures are explained clearly.
- Gemini/Veo is now connected to the Media Studio video provider router when `FREE_ONLY_MEDIA=false` and `GEMINI_API_KEY` is configured.
- Gemini long-running video operations are persisted and polled instead of creating duplicate paid requests.
- Provider status now distinguishes configured Gemini from paid-mode-enabled Gemini.

## Important
Remote Hugging Face and Pollinations video generation is not guaranteed to be free. Hugging Face documents monthly Inference Provider credits and additional paid usage; Pollinations returns HTTP 402 when the available pollen balance/key budget is insufficient.

For genuinely ₹0-cost video generation, configure a compatible local Hugging Face ZeroGPU video workflow and set:

```env
FREE_ONLY_MEDIA=true
```

For Gemini/Veo video, explicitly opt into paid media mode:

```env
FREE_ONLY_MEDIA=false
GEMINI_API_KEY=your_key_here
```


## GIF playback fix
- Local Wan2.2 output is GIF (`image/gif`).
- `/api/media/file/:name` now returns the correct GIF MIME type.
- Media Studio renders GIF video results with `<img>` so the browser animates them; MP4/WebM/MOV continue using `<video>`.
