# EditPrompt V9.1 — Creator Lab update

This patch upgrades the V9.0 source to V9.1.0. It adds a separate Creator Lab page and a small SQLite-backed public prompt marketplace.

## Added

1. **AI Background Remover** — runs `@imgly/background-removal` in the browser. The first run downloads model/WASM assets from jsDelivr and can use significant RAM. This dependency is not bundled into the app. Review the package's AGPL-3.0 licence and obligations before using it in a commercial deployment.
2. **Object Eraser** — local OpenCV Telea inpainting with a paint mask. This is classical inpainting, not generative AI; large or complex removals may leave artifacts.
3. **Speech-to-Text** — uses the browser Web Speech API. Availability and privacy behavior depend on browser/OS; some browsers use an online recognition service.
4. **MP3 Voice Export** — records microphone audio with MediaRecorder and encodes the recording to MP3 in the browser using lamejs. Requires HTTPS (or localhost), microphone permission, and a supported browser.
5. **Public Prompt Marketplace** — SQLite table plus public read/search and authenticated publishing endpoints. Prompts are immediately public after publishing; users should only share content they have rights to publish. The current patch does not include a moderation queue.
6. **Lightweight Timeline** — local video/audio/image clip list with start/trim controls, single-clip preview, and JSON project export. It does not render/export a finished MP4 and does not embed media files in the JSON.

## Changed files

- `package.json` — version 9.1.0

- `server.js` — marketplace table/routes, publish rate limit, and same-origin microphone permission
- `public/studio-tools.html` — link to the new Creator Lab
- `public/creator-lab-v91.html` — new Creator Lab UI
- `public/creator-lab-v91.js` — browser-side tools

## Apply

Copy the files from this patch into the matching paths in your existing V9 project, replacing files when prompted. Do not replace `.env`, `editprompt.db`, `media/`, or other user data.

Then run:

```powershell
npm install
node --check server.js
node --check public/creator-lab-v91.js
npm start
```

Open `http://localhost:3000/creator-lab-v91.html`.

For microphone features on a deployed site, use HTTPS. The app's Permissions-Policy now allows microphone access from the same origin; the camera remains disabled.
