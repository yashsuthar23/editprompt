# EditPrompt V7.1 Update

## Improvements
- Creator Presets for common video workflows
- Target-model selector for general AI video, Veo, Sora, Runway, Kling, Pika and Luma
- Improve Prompt action with AI-powered refinement and safe local fallback
- Production-oriented HTTP security headers
- Production secure session cookies
- Production session-secret validation
- Same-origin protection for mutating API requests
- Lightweight IP throttling on OTP, generation and improve endpoints
- OTP brute-force protection (maximum five incorrect attempts per code)
- Sensitive `.env` and local database removed from the distributable ZIP
- Clean `.env.example` with placeholders only

## UI
The existing dark EditPrompt design is preserved; new controls are added without replacing the generator layout.

## Production setup
1. Copy `.env.example` to `.env`.
2. Set a random `SESSION_SECRET` of at least 32 characters.
3. Add your OpenAI, Razorpay, SMTP and admin configuration.
4. Set `NODE_ENV=production` and the real `SITE_URL`.
5. Keep `.env` and `editprompt.db` out of source control/distribution.
