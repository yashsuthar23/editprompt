# EditPrompt V7.2 Update

## What changed

- Added a SQLite-backed `video_jobs` table so video jobs survive server restarts.
- Added video controls: camera motion, motion strength and FPS (24/30/60).
- Added a provider status indicator in Media Studio.
- Provider routing now prefers local ComfyUI first, then Hugging Face, then optional Pollinations when paid/community mode is enabled.
- `FREE_ONLY_MEDIA=true` no longer hides a configured local ComfyUI provider.
- Clarified that Hugging Face partner video providers may consume HF credits; local ComfyUI is the genuinely local/free path.
- Improved `.env.example` with the current video model variables and removed the duplicate `FREE_ONLY_MEDIA` setting.

## Important packaging note

The real `.env`, SQLite database files, `.git`, `node_modules`, generated media and the old Windows executable are intentionally excluded from the clean source package.

Run `npm install`, copy `.env.example` to `.env`, configure the providers you want, and run `npm start`.

The included `build.ps1` can rebuild `EditPrompt.exe` on Windows after these source changes.
