# EditPrompt V8.1 — Creator Studio Tools

## Added
- `public/studio-tools.html` and `public/studio-tools.js`: a before/after photo comparison, locally processed image adjustments and PNG export, advanced timestamped storyboard controls (camera, lighting, transitions, voice-over), social platform format presets, locally autosaved drafts, keyboard shortcut Ctrl/Cmd+S, and a saved Light/Dark preference.
- Provider diagnostics reuse `/api/media/providers/health`; no API key is returned to the browser and no provider is enabled automatically.
- Creator Projects API backed by SQLite: create/list/read/update/delete projects, attach/remove existing user-owned media, export a JSON manifest, and list/restore project snapshots. Project attachments reference `media_history`; they do not duplicate or delete source files. Snapshots are stored in `creator_project_versions`, capped at 50 per project, and restore only reattaches media still owned by the signed-in user.
- `/api/v8/status` safe status endpoint.
- Project version routes: `GET /api/projects/:id/versions` and `POST /api/projects/:id/versions/:versionId/restore`. Snapshots are user-scoped and require login.
- Strict free-first defaults in `.env.example`: `FREE_ONLY_MEDIA=true`, `PAID_VIDEO_ENABLED=false`, `GEMINI_VIDEO_ENABLED=false`.
- Version updated to 8.1.0; main navigation includes Creator Studio.

## Existing features preserved
The existing generator, provider routing, media history, prompt version APIs, queue/retry/cancel behavior, admin UI, and desktop scripts remain in place. No existing route or UI is intentionally removed.

## Important provider limitations
- The Creator Studio's photo adjustments run in the browser; they are not AI object removal, generative fill, or AI upscaling.
- Scene Builder and Reel/Ad Maker produce creative briefs/storyboards, not rendered videos.
- Gemini Omni supports iterative video edits/extension through its Interactions API, but this project’s existing video jobs do not persist Omni interaction IDs. Continuation is therefore not represented as working for existing Veo jobs. This tools page intentionally does not call Gemini Omni or any paid provider, in order to honor strict free-only mode.
- Free-tier availability and quota are not guaranteed. Hugging Face Inference Providers currently documents a small monthly free credit allowance that may change; do not advertise unlimited free generation.

## Upgrade safely
1. Back up the current project folder and `editprompt.db`.
2. Copy the updated source files over the project, but do **not** overwrite your real `.env` or database.
3. Keep `FREE_ONLY_MEDIA=true`, `PAID_VIDEO_ENABLED=false`, and `GEMINI_VIDEO_ENABLED=false` for strict free-only behavior.
4. Run `npm install` (Node.js >=22.5.0), then `node --check server.js`.
5. Start with `npm start`, sign in, and open `/studio-tools.html` and `/workspace.html`. The project-version table is created automatically on startup; do not delete or replace your existing database.
6. If you want to rebuild the Windows executable, run the existing `build.ps1` on Windows after testing the source.

## Security and packaging
The clean source archive intentionally excludes `.env`, SQLite databases, `.git`, `node_modules`, backups, and existing executable blobs. Keep private credentials and customer data in your local working copy.
